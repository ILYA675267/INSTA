# ИИ-ролики для Instagram (монетизация)

Отвечай по-русски, просто, без терминов. Пользователь присылает тему → ты делаешь ролик целиком,
присылаешь его в чат и **публикуешь только после явного «Выкладывай»**.

## Формат
Reels 9:16, 1080×1920, ~30 с. Основной стиль — **дудл**: нарисованный от руки персонаж
(`tools/doodle.py`), клетчатый фон медленно «плывёт», линии слегка дрожат, мини-анимации
(иконки, надписи с жёлтым маркером, кружки-номера) появляются в момент, когда звучит слово.
Субтитры фразами по 2–4 слова над головой персонажа. Шрифт — Caveat Bold (`fonts/Caveat.ttf`).

## Шаблон ролика (правила пользователя — для КАЖДОГО ролика)
Герой — **Эмбер** (рисованный персонаж): **красная футболка (без логотипов брендов — решение пользователя), синие шорты, золотистые часы на руке** (`WATCH`, `SHIRT`/`SHORTS` в tools/doodle.py, образец `assets/brand/ember_outfit.png`). В сценарии обязательно:
1. **Хук** в первые 1–2 с (+ заголовок-«крючок» на первом кадре).
2. Перед тем как начать объяснять/рассказывать — фраза **«Эмбер объяснит простыми словами»**.
3. **Только если ролик про нейросети/ИИ** — фраза ближе к концу: **«Кстати, даже это видео смонтировано с помощью нейросети»**.
   Если тема другая — эту фразу НЕ вставлять.
4. **В конце всегда** — призыв подписаться на Telegram-канал: «Подписывайся на мой телеграм-канал — ссылка в шапке
   профиля» + вставка `"type": "tg"` (стеклянная карточка: аватар Эмбер `assets/brand/ember_avatar.png`, «Ember ·
   Telegram-канал · t.me/ember_aii», голубая кнопка «Подписаться», палец нажимает; превью `assets/brand/tg_card_preview.png`).
   Канал: https://t.me/ember_aii

## Стиль вставок — реалистичный (выбор пользователя)
В plan.json всегда `"style": "real"`, `"sfx": true` (`tools/real.py`, `tools/sfx.py`): персонаж и фон остаются
рисованными, а вставки — «как настоящие»: графики и таблицы на матовом стекле с цветным свечением, столбики
с градиентом и бликом, галочки — зелёные глянцевые кружки, номера — оранжевые глянцевые шарики, иконки — эмодзи
на стеклянной плитке (`"emoji": "🚀"`), надпись с `"mark"` — кнопка с градиентом («Подписаться»), вспышка — мягкий свет.
Тихие звуки сами ставятся на появление: пузырёк (номера, иконки, галочки), «вжух» (логотипы, карточки, графики),
«дзынь» (вспышка), растущий тон (столбики). Пример: `work/claude_novichok/plan_v2.json`.

## Приёмы монтажа (референс IMG_8284 — пользователю очень нравится)
- Логотипы компаний в кружках с мягкой тенью, выезжают слева с серым «шлейфом» (`"type": "logo"`,
  ChatGPT — чёрный кружок, белый знак). Библиотека: `assets/logos/` (112 шт., список и цвета в index.json).
- 3D-карточки: белая карточка с наклоном (перспектива), тенью, влетает снизу (`"type": "card"`).
- Кинетический текст: слова появляются по одному в такт речи, серые → чёрные, ключевое слово в чёрной
  плашке (`"type": "kinetic"`, `"pill"`).
- Оранжевая «вспышка» Claude из угла на смене частей (`"type": "burst"`), размытие на смене сцен.
- Персонаж не стоит на месте: подпрыгивает на номерах (`"jump"`), крупный план лица (`"type": "zoom"`),
  отходит в угол, уступая экран графику/таблице (`"type": "chart"`: bars, iso (3D-столбики), line, pie, table).
- Цифры на графиках — только правдоподобные и без выдуманной статистики.

## Как сделать ролик (папка work/<имя>/)
1. `script.txt` — сценарий ~70 слов на 30 с: хук в первые 2 с, 3–4 пункта, призыв «Сохрани/подписывайся».
   Иностранные названия писать по-русски («Клод»), иначе голос читает неверно.
2. Голос — **основной: Zvukogram «Борислав»** (выбор пользователя):
   `python3 tools/voice_zvuk.py script.txt voice.wav Борислав 1.0` (нужны ZVUKOGRAM_TOKEN/ZVUKOGRAM_EMAIL
   в переменных среды и zvukogram.com в разрешённых доменах). Ещё понравился «Lucien RU» — он медленнее,
   ставить скорость 1.2 (`... "Lucien RU" 1.2`). Запасной бесплатный (Silero v5, MIT): `python3 tools/voice.py script.txt voice.wav ru_marat 1.12 0`
   (`pip install torch librosa sherpa-onnx numpy pillow`; модель скачается в models/).
   Другие мягкие мужские голоса: ru_eduard, ru_dmitriy, ru_igor; последний параметр — высота (+2 = моложе).
3. Тайминги: `python3 tools/transcribe.py voice.wav asr.json` →
   `python3 tools/align.py script.txt asr.json words.json`.
4. `plan.json` — какие мини-анимации и на каких словах (формат в начале `tools/doodle.py`,
   пример `work/claude_plusy/plan_v4.json`; `"corner_logo"` — крутящийся логотип Клода в углу).
4а. Фоновая музыка (своя, без авторских прав) — тихая, но бодрая: `python3 tools/music.py work/<имя>/music.wav <длительность+1>`
   (спокойный вариант — добавить `7 calm`),
   в plan.json — `"music": "work/<имя>/music.wav"` (очень тихо, под речью приглушается сама).
5. Рендер: `python3 tools/doodle.py voice.wav words.json plan.json output/<имя>.mp4` (~1,5 мин).
6. Проверить кадры (ffmpeg select), отправить пользователю.

## Качество видео (настроено, не откатывать)
- Remotion (`remotion/remotion.config.ts`): кадры PNG (без потерь, не JPEG), CRF 12, preset slow,
  `yuv420p` + `bt709` (стандартная шкала — «полный диапазон» Instagram пересчитывает и картинка блёкнет).
- Подложка `tools/doodle.py` в режиме bg_only — CRF 10 (почти без потерь), обычный рендер — CRF 15, preset slow.
- Итог ~8 Мбит/с вместо ~3,8: запас на повторное сжатие Instagram. Финальная склейка звука — без пережатия видео (`-c:v copy`).
- Сильнее всего Instagram «мылит» мелкие детали, которые меняются каждый кадр (весь клетчатый фон «плывёт»).

## Публикация — Buffer API
Ключ лежит в сетевых секретах среды (подставляется сам для api.buffer.com, в коде его нет).
GraphQL `https://api.buffer.com/graphql`. Организация `6ac7e4ff283372fa1f7e397b`,
канал Instagram **@ember_rea** `6ac7e7346a5c39ccb655425b`. Мутация `createPost`
(assets — ссылка на видео в интернете, mode, schedulingType). Видео нужно сначала выложить
по публичной ссылке (репозиторий публичный: `https://raw.githubusercontent.com/ILYA675267/INSTA/<коммит>/output/<файл>.mp4`).
Пометка ИИ — только ярлыком: `aiAssisted: true` и `metadata.instagram.isAiGenerated: true`. В текст поста фразу
«создано с помощью ИИ» НЕ писать: описание — только суть ролика (например, список плюсов) + хэштеги,
`metadata.instagram.type: reel`, `shouldShareToFeed: true`, `mode: shareNow`.
Описание (правило пользователя для всех публикаций) — РОВНО две строки, без пунктов, призывов и хэштегов:
```
<суть видео кратко, например: 3 способа заработать на нейросетях>
Телеграм: Ember
```
Монетизация в Instagram включается
на уровне аккаунта (Профессиональная панель → Монетизация), отдельного «флажка монетизации» для поста в Buffer API нет;
Обложка обязательна: кадр с крупным планом героя + крупный заголовок на стеклянной плашке в центре (зона 3:4 — её видно
в сетке профиля). Buffer НЕ принимает свою картинку (`thumbnailUrl` — ошибка), только кадр из видео:
`assets[].video.metadata.thumbnailOffset` в мс. Поэтому в начале ролика всегда заголовок-«крючок» (`"type": "hook"` в
tools/reel.py, первые ~1,2 с) и `thumbnailOffset: 300`. Первый кадр — чёткий, без размытия перехода. «Платное партнёрство» не ставить — это только для рекламы по договору с брендом. Перед публикацией — всегда «Выкладывай» от пользователя.
