# Раскадровка: «Почему на нейросетях можно хорошо заработать» (~60 с, голос — пользователь)

| Фраза | На экране |
|---|---|
| «Пока одни боятся… отнимут работу» | крупный план героя; эмодзи 😨 на стекле слева |
| «…другие уже на них зарабатывают» | герой ухмыляется; эмодзи 💸 справа, «вжух» |
| «Почему так? Смотри.» | герой указывает вниз; вспышка света |
| **Первое.** «минуты вместо часов» | шарик «1»; стеклянная карточка «часы → минуты» с часами ⏰ |
| «Тексты, картинки, монтаж, таблицы» | 4 стеклянные плитки выпрыгивают по слову: 📝 🖼️ 🎬 📊 |
| «больше заказов… заработать больше» | герой в угол; график-линия «заказы в неделю» (без цифр, только рост) |
| **Второе.** «начать почти ничего не стоит» | шарик «2»; кинетический текст, плашка на «ничего» |
| «Не нужен диплом и дорогое оборудование» | 🎓 и 💻 зачёркиваются красным |
| «телефон, интернет и желание» | три зелёные галочки: 📱 🌐 🔥 |
| **Третье.** «бизнесу нужно прямо сейчас» | шарик «3»; стеклянная таблица «кому — что нужно»: магазин / блогер / кафе |
| «людей, которые умеют, пока мало» | 3D-весы или столбики «спрос / умеющие» без чисел |
| **Четвёртое.** «продавать не только время» | шарик «4»; карточки: шаблоны, подсказки, обучение, контент |
| «Один раз сделал — продаёшь много раз» | одна карточка размножается веером ×5, звуки «пузырьков» |
| «не волшебная кнопка с деньгами» | 3D-кнопка «💰» нажимается — и зачёркивается |
| «платят за задачи, которые решаешь» | кинетический текст, плашка на «задачи» |
| «Сохрани… подписывайся» | 🔖 + кнопка «Подписаться», сердечко ❤️ |

Постоянно: субтитры с подсветкой текущего слова, крутящийся логотип в углу, тихая бодрая музыка, звуки появления.
Цифр и статистики нет — только «больше/меньше», чтобы ничего не выдумывать.
